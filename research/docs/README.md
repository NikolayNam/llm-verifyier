# Research Supplemental Docs

Status: active  
Scope: repository root `research/docs/`  
Audience: researchers, analysts, and AI agents

## Purpose

`research/docs/` stores supplemental synthesized research reading surfaces.

Use this directory for:

- short derived matrices or synthesis notes built from active research docs;
- operator-facing interpretive documents that summarize the current state of a
  narrow research line;
- convenience reading layers that should not replace benchmark-family specs or
  active guardrail matrices.

Do not use this directory for:

- canonical benchmark-family specifications;
- canonical runbooks;
- active guardrail matrices that belong under `research/active/matrix/`;
- machine-generated result artifacts that belong under `research/artifacts/`.
