# Research Prompts

This directory stores research prompt registries and prompt-family notes.

Use `prompts/` when the document answers questions such as:

- which prompt versions exist for a research family
- which version is the engineering-best snapshot
- which version is the cleaner evaluation baseline
- where the prompt family is implemented in code
