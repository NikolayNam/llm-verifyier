# Research Documents (RU)

Этот каталог хранит ручные русские companion-копии отдельных документов из
`research/active/documents/`.

Правило источника истины:

- canonical operator-facing source остаётся в английском файле уровнем выше
- русские файлы в `ru/` синхронизируются вручную и могут временно отставать
- если между версиями есть расхождение, для точных путей, флагов и команд
  сначала проверяй английский оригинал

Сейчас здесь лежат русские companion-версии runbook для:

- `proof-research-phase1-runbook.md`
- `proof-research-phase2-runbook.md`
- `proof-research-phase3-runbook.md`
